# Paper2Gather

LaTeX 수식, 자동 번호, 참고문헌 관리를 지원하는 실시간 공동 논문 작성 사이트.

| 경로 | 구성 |
| --- | --- |
| `frontend/` | Next.js 16 (App Router) · React 19 · TipTap 3 · shadcn/ui · KaTeX · dnd-kit |
| `backend/` | Node.js · Express 5 · `ws` · Yjs (y-websocket 프로토콜 호환 서버) · MCP 서버 |

## 실행

Node.js 20 이상이 필요합니다. 처음 한 번 세 폴더에서 패키지를 설치하고, 루트에서 실행합니다.

```bash
# 설치 (처음 한 번)
cd backend && npm install && cd ..
cd frontend && npm install && cd ..
npm install

# 실행 — http://localhost:6005
npm run dev
```

루트의 `npm run dev`(`server.mjs`)는 백엔드(`backend`의 `npm run dev`, 127.0.0.1:1234)와 프런트엔드(`frontend`의 `npm run dev`, 127.0.0.1:3000)를 함께 띄우고, 6005 포트 하나로 요청을 나눠 보냅니다. `/api/…`, `/uploads/…`, `/mcp`, `/collab/…`(WebSocket)은 백엔드로, 나머지는 프런트엔드로 갑니다. 두 서버는 이 PC 안에서만 열리므로 브라우저와 MCP 클라이언트는 6005로 접속합니다. `Ctrl+C`로 셋 모두 종료됩니다.

프로덕션(루트 서버는 개발용): `backend`에서 `npm run build && npm start`, `frontend`에서 `npm run build && npm start`. 이때는 루트 서버가 없으므로 `frontend`를 빌드할 때 `NEXT_PUBLIC_API_URL`에 백엔드 주소를 줍니다.

`frontend`의 `npm install`은 TikZ 그림용 TeX 엔진 파일(약 8 MB)을 `public/tikzjax/`로 복사합니다(`postinstall`). 이 폴더가 없으면 `node scripts/copy-tikzjax.mjs`로 다시 복사합니다.

같은 문서 URL을 다른 브라우저(또는 시크릿 창)에서 열면 실시간 공동 편집을 확인할 수 있습니다.

다른 PC에서는 `http://<이 PC의 IP>:6005`로 접속합니다. 프런트엔드는 페이지를 연 주소에서 백엔드를 찾으므로, 방화벽에서는 6005 포트만 열면 됩니다. 개발 서버(`npm run dev`)는 이 PC의 이름과 IPv4 주소(LAN·VPN)로 들어오는 접속만 허용하므로, 도메인이나 터널 주소로 열려면 `ALLOWED_DEV_ORIGINS`에 추가합니다.

## 환경 변수

**루트 서버** (`server.mjs`)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `6005` | 접속 포트 (HTTP·WebSocket) |
| `HOST` | (미지정 = 듀얼 스택) | 바인딩 주소 |

아래 변수는 루트 서버를 띄운 환경에서 백엔드·프런트엔드로 그대로 전달됩니다. 단 루트 서버로 띄울 때 백엔드의 `PORT`·`HOST`는 `1234`·`127.0.0.1`로 고정됩니다.

**backend**

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `1234` | HTTP·WebSocket 포트 |
| `HOST` | (미지정 = 듀얼 스택) | 바인딩 주소 |
| `DATA_DIR` | `./data` | 문서(`docs/*.bin`, `*.json`)와 업로드 이미지(`uploads/`) 저장 위치 |
| `CORS_ORIGIN` | `*` | 허용 Origin (쉼표 구분) |
| `SAVE_DEBOUNCE_MS` | `1000` | 변경 후 저장까지 대기 시간 |
| `SAVE_MAX_WAIT_MS` | `5000` | 계속 편집 중이어도 이 시간 안에는 저장 |
| `MAX_UPLOAD_BYTES` | `15728640` | 이미지 업로드 최대 크기 |

**frontend** (`NEXT_PUBLIC_*`는 빌드 시점에 포함됨)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | 페이지를 연 주소 (루트 서버) | 백엔드 주소 (예: `https://api.example.com`) |
| `NEXT_PUBLIC_COLLAB_URL` | API 주소의 `ws(s)://…/collab` | 실시간 편집 WebSocket 주소 |
| `ALLOWED_DEV_ORIGINS` | (없음) | `npm run dev`에 접속을 허용할 호스트 추가 (쉼표 구분, 예: `*.example.com`). 이 PC의 이름과 IPv4 주소는 자동으로 허용 |

## 주요 기능

- **실시간 공동 편집**: Yjs CRDT. 접속자 아바타, 다른 사용자의 커서·선택 영역 표시, 재연결 시 자동 병합.
- **수식**: 빈 문단에서 `$$` + 스페이스로 수식 블록, `$…$`로 인라인 수식. 단축키는 `Ctrl+Alt+E`(블록), `Ctrl+Shift+E`(인라인). 기호 팔레트와 실시간 미리보기를 제공합니다. 블록 수식 편집기는 문서 위에 떠서 열어도 배치가 바뀌지 않습니다. 번호와 한 줄에 들어가지 않는 긴 수식은 번호를 다음 줄로 내리고, 줄보다 길면 가로 스크롤 없이 오른쪽 여백으로 넘쳐 보입니다(쪽 끝에서 잘림).
- **자동 번호**: 수식·그림·표·절 번호를 문서 순서대로 매깁니다. 수식 번호는 문서 전체 또는 절 단위(예: (2.1))로 고를 수 있습니다.
- **문서 양식**: 헤더의 톱니바퀴 버튼으로 엽니다. 논문 제목·본문·제목 1~3·캡션·참고문헌의 단락 스타일(영문·한글 글꼴 — 기본값 Times New Roman / Noto Serif KR, 크기, 굵게/기울임, 색, 정렬, 줄 간격, 단락 앞뒤 간격, 첫 줄 들여쓰기, 제목의 영문 대문자·작은 대문자)과 그림·표 캡션 형식(라벨, 번호 형식 1/I/i/A/a, 구분자, 위/아래 위치, 라벨 굵게), 수식 번호 괄호, 본문 참조 표기, 제목 번호 형식(1 / 1. / IEEE식 I. A. 1) / 번호 없음), 용지(A4·US Letter)와 여백, 인용 양식(아래 참고문헌)을 정합니다. 모든 공동 작업자에게 똑같이 적용되고, LaTeX 내보내기에는 고른 문서 클래스(article·IEEEtran·llncs·apa7)와 캡션·번호 형식, 인용 양식만 반영됩니다(클래스 파일은 함께 내보내지 않음). `논문 양식` 탭에서 IEEE 스타일·Springer LNCS 스타일·APA 7판 스타일·국문 학술지(일반형)를 인용 양식까지 한 번에 적용할 수 있습니다(국문 학술지는 IEEE식 번호 인용). 각 기관의 저자 안내에서 수치만 따온 1단 근사이며 공식 템플릿이 아니고, 적용하면 문서 양식 전체가 바뀝니다.
- **직접 서식**: 툴바에서 선택한 글자의 영문·한글 글꼴(한 메뉴에서 따로 선택)·크기·색과 문단 정렬을 바꾸고, `서식 지우기`로 단락 스타일로 되돌립니다. 함초롬바탕·휴먼명조·맑은 고딕은 그 글꼴이 설치된 PC에서만 그대로 보이고, 없으면 Noto 글꼴로 대신 표시됩니다.
- **쪽 나눔**: 편집 화면이 문서 양식의 용지·여백(기본값 A4, 여백 25 mm) 쪽으로 나뉘고 쪽 번호가 붙습니다. 쪽 아래 여백을 넘는 문단은 줄 단위로 다음 쪽에 이어지고, 제목은 다음 내용과 같은 쪽에 놓입니다. 수식·그림·표는 통째로 넘어가며, 한 쪽보다 긴 표만 행 단위로 나뉩니다. 인쇄(PDF)도 같은 쪽 크기·여백으로 나뉩니다. 오른쪽 패널 옆에 남은 폭이 쪽 폭보다 좁으면 쪽을 그 폭에 맞게 축소해 보여줍니다(인쇄는 실제 크기).
- **표 편집**: 캐럿이 있는 표는 보이지 않는 셀 구분선을 점선으로 보여줍니다(화면에서만). 세로 경계선 근처를 드래그하면 열 너비가, 가로 경계선 근처를 드래그하면 행 높이가 바뀝니다. 너비·높이는 편집 화면과 인쇄에만 반영되고 LaTeX 내보내기에는 반영되지 않습니다.
- **TikZ 그림**: 툴바의 `TikZ 그림` 또는 `/tikz`로 엽니다. 왼쪽에 TikZ 코드(`\begin{tikzpicture}…\end{tikzpicture}`)를 쓰면 입력을 멈추고 약 1초 뒤 오른쪽 미리보기가 갱신되고(`Ctrl+Enter`는 바로), TeX 오류는 줄 번호와 함께 보여 줍니다. 그림마다 패키지(pgfplots, tikz-cd, circuitikz, chemfig, tikz-3dplot, tikz-feynhand, amsmath, amssymb, array)와 TikZ 라이브러리를 골라 켭니다. 일반 그림처럼 번호·캡션·라벨·상호 참조가 붙고, 그림을 더블클릭하면 다시 고칩니다. 너비는 `원래 크기`(코드에 정한 크기) 또는 본문 폭의 25~100%입니다. 문서에는 코드만 저장되고 각 브라우저가 TeX 엔진(TikZJax, 처음 한 번 약 8 MB)으로 그린 뒤 브라우저에 캐시합니다. 그림 안 글자에는 한글을 쓸 수 없고(영문·수식만), 목록에 없는 패키지는 불러올 수 없습니다. LaTeX 내보내기에는 코드가 그대로 들어가고 필요한 `\usepackage`·`\usetikzlibrary`가 붙습니다.
- **HWPX 가져오기**: 문서 목록의 `HWPX 가져오기`로 한글 문서(`.hwpx`)를 새 논문으로 변환합니다(브라우저에서 변환). 개요 1~3 수준·제목 스타일 → 절 제목, 굵게·기울임·밑줄·취소선·위/아래 첨자·글자색·가운데/오른쪽 정렬·하이퍼링크, 한글 수식 → LaTeX 수식, 표(병합 셀·열 너비·캡션) → 표, 그림 → 그림, 글머리표·번호 목록을 옮기고, 각주·미주는 본문의 위 첨자 번호와 문서 끝 `각주` 절로 옮깁니다. 글꼴 이름·글자 크기는 가져오지 않고 문서 양식을 따릅니다. HWP(바이너리) 파일은 한글에서 HWPX로 저장한 뒤 가져와야 하고, WMF·EMF 그림은 빈 그림으로, OLE 개체·차트는 빠집니다.
- **HWPX 내보내기**: `내보내기` 메뉴의 `한글 (.hwpx)`에서 수식을 넣는 방식을 고릅니다(브라우저에서 변환). `한글 수식`은 한글에서 고칠 수 있고, 바꿀 수 없는 수식은 이미지로 들어가며 그 개수를 알려 줍니다. `이미지`는 화면과 같은 모양입니다. 문서 양식은 한글 스타일로 옮기고 표(병합 셀)·그림·목록·인용 표시·참고문헌(인용 양식대로)·링크를 넣으며, TikZ 그림은 PNG로 들어갑니다. 절·수식·그림·표 번호와 상호 참조는 화면과 같은 글자로 고정되어 한글에서 고쳐도 갱신되지 않고, 댓글은 빠집니다. 쪽수는 화면·PDF와 다를 수 있고, 설치되지 않은 글꼴은 한글이 다른 글꼴로 바꿉니다.
- **Word 내보내기**: `내보내기` 메뉴의 `Word (.docx)`에서 수식을 넣는 방식을 고릅니다(브라우저에서 변환). `Word 수식`은 Word에서 고칠 수 있고, 바꿀 수 없는 수식은 이미지로 들어가며 그 개수를 알려 줍니다. `이미지`는 화면과 같은 모양입니다. 문서 양식은 Word 스타일(제목, 제목 1~3, 캡션, 참고 문헌)로 옮기고 표(병합 셀)·그림·목록·인용 표시·참고문헌(인용 양식대로)·링크를 넣으며, TikZ 그림은 PNG로 들어갑니다. 절·수식·그림·표 번호와 상호 참조는 화면과 같은 글자로 고정되고, 상호 참조를 누르면 그 대상으로 이동합니다. 댓글은 답글과 함께 Word 메모로 들어가고, 해결된 댓글은 '해결됨'으로 표시되며, 댓글을 단 글이 지워진 댓글은 빠집니다. 쪽수는 화면·PDF와 다를 수 있고, 설치되지 않은 글꼴은 Word가 다른 글꼴로 바꿉니다.
- **상호 참조**: `Eq. (3)`, `Fig. 2`, `Section 1` 등을 삽입하면 번호가 바뀔 때 함께 갱신됩니다.
- **부록**: 툴바의 `부록 시작` 또는 `/부록`으로 넣은 구분선 뒤의 제목 1이 `Appendix A`, `Appendix B` …(국문: `부록 A`)가 되고(LaTeX `\appendix`와 같음), 하위 절은 A.1, A.1.1로 매겨집니다. 부록마다 수식 (A.1), 그림 A.1, 표 A.1로 번호를 새로 시작하며, 참조는 `Appendix A`, `Appendix A.1`로 표시됩니다. 참고문헌은 항상 문서 끝(부록 뒤)에 놓입니다. 구분선은 문서에 하나만 둘 수 있고 화면에만 보입니다. 표기는 문서 양식의 `부록 표기`에서 바꿉니다.
- **참고문헌**: 직접 입력, DOI 조회(Crossref), BibTeX 가져오기·내보내기(월·편집자·출판 지역·판·시리즈·접속일 포함). 미인용 항목 정리도 지원합니다.
- **인용 양식**: 문서 양식의 `인용·참고문헌 목록`에서 고르며, 본문 인용 표시·목록 순서·목록 글자가 모두 양식을 따릅니다.
  - `기본 (번호)` [1, 3–5], `IEEE` [1], [3], [4](2025 IEEE Reference Guide), `Springer LNCS` [1, 3–5](목록은 저자·연도 순), `APA 7판` (Kim & Lee, 2020; Park et al., 2021)(목록은 번호 없이 저자·연도 순, 내어쓰기 0.5 in).
  - APA는 세 명 이상 et al., 첫 저자 성이 같으면 이니셜, 같은 저자·연도는 2020a·2020b, 연도 없음은 n.d.로 씁니다. 국문 문헌은 (홍길동, 김철수, 2020), 서술형 홍길동과 김철수(2020), 세 명 이상 `홍길동 외`로 쓰고, 목록에서 국문 문헌을 먼저(가나다 순) 놓으며 학술지명은 기울이지 않습니다. 한글 이름은 입력한 대로 씁니다.
  - 목록 순서는 `양식대로`(번호 양식은 처음 인용한 순, LNCS·APA는 저자·연도 순)나 `직접 정렬`(사이드바에서 **드래그로 순서를 바꾸면 본문 인용 번호가 즉시 바뀝니다**)로 고릅니다. `직접 정렬`에서는 인용 순서대로 번호 정렬도 됩니다.
  - 인용 대화상자에서 쪽 같은 위치를 붙이고(`p. 5` → [1, p. 5], (Kim, 2020, p. 5)), APA에서는 괄호형 (Kim, 2020)과 서술형 Kim (2020)을 고릅니다.
  - `인용하지 않은 문헌도 목록에 넣기`를 끄면 인용하지 않은 문헌은 화면에만 흐리게 남고 인쇄·내보내기에서는 빠집니다.
  - 제목의 대소문자(APA의 문장형 등)는 바꾸지 않고 입력한 대로 씁니다.
- **댓글**: 텍스트를 선택해 스레드를 만들고, 답글·해결·삭제할 수 있습니다.
- **내보내기**: `.tex`(abstract, equation, figure, table, `\cite`, `\eqref`, 참고문헌 포함), `.bib`, 한글 `.hwpx`, Word `.docx`, 인쇄(PDF로 저장).
  - `.tex`의 참고문헌은 `기본 (번호)`이면 화면과 같은 글자의 thebibliography입니다. IEEE·LNCS·APA는 `.tex` 앞머리의 `filecontents*`가 컴파일할 때 `paper2gather-refs.bib`를 써 두고, 각 양식의 공식 스타일(IEEEtran.bst·splncs04.bst는 bibtex로, biblatex-apa는 biber로 컴파일)이 목록을 만듭니다.
  - 그래서 LaTeX 쪽 목록 글자는 스타일 파일이 정하고, LNCS·APA 목록은 스타일이 정렬하므로 `직접 정렬` 순서가 반영되지 않습니다. biblatex-apa는 국문 규칙(외, 국문 먼저)을 따르지 않습니다.
- `/` 슬래시 명령, 라이트/다크 테마, 영문/국문 라벨 프리셋(Eq./식, Fig./그림 …), 드래그로 너비를 조절하는 오른쪽 패널.

## MCP 서버 (AI 에이전트 연동)

백엔드의 `/mcp`(예: `http://localhost:6005/mcp`)가 MCP 서버(Streamable HTTP)입니다. Claude Code 같은 MCP 클라이언트가 논문을 읽고 고칠 수 있고, 고친 내용은 그 논문을 열어 둔 모든 사람의 화면에 공동 작업자의 편집처럼 바로 나타납니다.

```bash
# Claude Code에 등록
claude mcp add --transport http paper2gather http://localhost:6005/mcp
```

설정 파일로 등록하는 클라이언트는 `{"mcpServers": {"paper2gather": {"type": "http", "url": "http://localhost:6005/mcp"}}}` 형식을 씁니다.

| 도구 | 설명 |
| --- | --- |
| `list_papers`, `create_paper` | 논문 목록, 새 논문(기본 절 구성, 빈 문서 또는 마크다운 내용으로). `prefab`(`ieee`·`lncs`·`apa`·`kr-journal`)으로 논문 양식과 그 절 구성을 고를 수 있음 |
| `read_paper` | 논문을 마크다운으로 읽기. 블록마다 `<!-- #블록ID · Eq. (2) -->` 주석으로 편집용 ID와 번호를 보여 줌. `outline`(절·수식·그림·표 목록), `section`(한 절만) 지원 |
| `insert_blocks`, `replace_blocks`, `delete_blocks` | 블록 삽입(처음·끝·블록 앞뒤·절 끝), 교체, 삭제 |
| `edit_text` | 문단 안의 글자 찾아 바꾸기(주변 서식과 댓글 표시 유지) |
| `update_paper_info` | 제목, 저자 |
| `list_references`, `add_references`, `update_reference`, `delete_reference` | 참고문헌 |
| `list_comments`, `add_comment`, `reply_comment`, `resolve_comment` | 댓글 |

마크다운에서는 `#`~`###` 제목, `$…$`·`$$…$$` 수식(`\begin{equation}`·`align`도 가능), `\cite{키}`(또는 `[@키]`) 인용, `\cite[p. 5]{키}`(또는 `[@키, p. 5]`) 위치를 붙인 인용, `\citet{키}` 서술형 인용(APA에서 Kim (2020)), `\ref{라벨}` 상호 참조, `![캡션](이미지 URL)` 그림, ` ```tikz ` 코드 블록 TikZ 그림(`Figure: 캡션` 줄, `{#fig:라벨 width=60 libraries=arrows.meta packages=pgfplots}` 속성), 파이프 표(`Table: 캡션` 줄), 목록·인용문·코드 블록, `\appendix`를 씁니다. 라벨은 `{#eq:loss}`처럼 붙이고(`{-}`는 번호 없음), 다시 쓸 때 같은 라벨을 두면 그 대상을 가리키던 참조가 유지됩니다. 자세한 문법은 서버가 MCP `instructions`로 클라이언트에 알려 줍니다.

- `replace_blocks`는 블록을 새로 쓰므로 마크다운으로 나타낼 수 없는 서식(글꼴·색·정렬)과 댓글 표시가 빠집니다. 문장 단위 수정은 `edit_text`를 쓰면 유지됩니다.
- 표의 병합 셀·열 너비는 읽을 때 펼쳐 보이고, 표를 `replace_blocks`로 다시 쓰면 병합이 풀립니다.
- 그림은 이미지 URL(`http(s)://…` 또는 `/uploads/…`)로만 넣을 수 있습니다.
- TikZ 그림은 서버가 컴파일하지 않으므로 코드의 TeX 오류는 논문을 연 브라우저에서 그림 자리에 표시됩니다.

## 현재 제약

- 인증이 없습니다. 링크를 아는 사람은 누구나 편집할 수 있고, 사용자 이름은 브라우저 localStorage에 저장됩니다. MCP 엔드포인트(`/mcp`)도 6005 포트에 접속할 수 있으면 누구나 쓸 수 있습니다.
- 저장소는 로컬 파일(`DATA_DIR`)입니다. 서버를 여러 대로 늘리려면 DB나 공유 스토리지가 필요합니다.
